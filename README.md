# Perfume E-Commerce Website

## Overview
A full-featured **Perfume E-Commerce Web Application** built using ASP.NET MVC.  
The application provides a complete online shopping experience with role-based access, clean architecture using MVC Areas, and bilingual support.

---

## Features

- **Product Catalog**
  - Display perfumes with detailed descriptions and prices  

- **Search Functionality**
  - Fast and user-friendly product search  

- **Shopping Cart**
  - Add and manage products before checkout  

- **Order via Email**
  - Orders are sent directly to the website owner via email  

- **Authentication System**
  - User Registration (Sign Up)  
  - User Login (Sign In)  

---

## Architecture (MVC Areas)

The application is structured using **ASP.NET MVC Areas**:

### User Area
- Browse products  
- Search products  
- Add to cart  
- Place orders  
- View personal orders (User Dashboard)  

### Admin Area
- Add new products  
- Manage product listings  
- Control system content  

---

## Dashboards

- **User Dashboard**
  - View and track orders  

- **Admin Dashboard**
  - Manage products and system data

## ⚙️ How It Works

1. Users browse available perfumes  
2. Add products to the shopping cart  
3. Submit an order  
4. The order is sent via email to the website owner  
5. Users can track their orders through the dashboard  
6. Admin manages products via the admin panel
